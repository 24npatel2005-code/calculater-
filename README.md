# Modern Calculator

A modern, accessible web-based calculator built with HTML, CSS, and JavaScript.

## Features

- ✨ Full arithmetic operations (+, -, ×, ÷)
- 💾 Memory functions (MC/MR/M+/M-)
- 📜 Persistent calculation history (localStorage)
- ⌨️ Keyboard support for all operations
- 📱 Fully responsive design
- ♿ Accessibility features

## Live Demo

Visit: https://24npatel2005-code.github.io/calculater-/

## How to Use Locally

1. Clone the repository:
```bash
git clone https://github.com/24npatel2005-code/calculater-.git
cd calculater-
```

2. Open `index.html` in your browser or run a local server:
```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`

## Files

- `index.html` - Calculator structure
- `styles.css` - Styling and responsive design
- `script.js` - Full calculator functionality

## Features in Detail

### Arithmetic Operations
- Addition, Subtraction, Multiplication, Division
- Decimal point support
- Percentage calculations
- Sign toggle (±)

### Memory Functions
- MC (Memory Clear)
- MR (Memory Recall)
- M+ (Memory Add)
- M- (Memory Subtract)

### History
- Automatic calculation history tracking
- Click any history item to reuse result
- Clear history option

### Keyboard Support
- Number keys (0-9)
- Operators (+, -, *, /)
- Enter or = to calculate
- Backspace to delete
- Escape to clear

## Browser Support

- Chrome/Edge (latest)
- Firefox (latest)
- Safari (latest)
- Mobile browsers
